# PocketInstall 0.1.0 — historical diagnostic POC

Historical Android and x64 EFI proof-of-concept binaries, with SHA-256 checksums. The EFI displays a startup confirmation and shuts down; it does not install Windows or write disks. Native UEFI HTTP boot depends on firmware/network support. The MIT license and earlier grants remain applicable to this release.

Use the matching historical artifacts and original evidence for this version. Current OS-installation instructions are in the root README; they must not be attributed to this POC.
