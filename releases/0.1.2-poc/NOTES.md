# PocketInstall 0.1.2 — experimental USB networking

Adds manually enabled Android USB tethering as an experimental network transport. The PC firmware must recognize the phone's USB network function and support booting through it. The app does not emulate USB mass storage or turn an arbitrary cable into a bootable drive.

The diagnostic EFI remains disk-free. This release does not validate WinPE, Windows installation or every phone/firmware combination. Test networking and EFI startup separately.
