# PocketInstall 3.3.0 — logo and languages

Adds the approved pocket/down-arrow logo, adaptive/monochrome icons and a brief startup animation that respects disabled system animations. Fresh installations explicitly choose French, US English, German, Spanish, Japanese or Simplified Chinese; Help permits later changes.

Locale persistence uses AppCompat/system per-app settings as appropriate. Main navigation/guides/options are translated; detailed diagnostics, PC messages and Microsoft pages can retain their original language. App language does not change Windows media language.

No Freebox or WinPE environment change is required. See docs/APP_LANGUAGE.md for language persistence and manual accessibility checks.
